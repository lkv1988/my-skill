# Working in This Repository

The author leads the content and refinement of these skills. Help polish wording, correct obvious mistakes, and identify omissions. Discuss substantive additions or changes of viewpoint with the author.

## Skill Sources and Layout

- Keep this repository as the source of truth for its skills.
- Place each skill in `skills/<skill-name>/`, with `SKILL.md` as its entry point.
- Keep each skill focused on a clear purpose or set of related work scenarios.
- Add scripts and supporting material when they serve the workflow.

## Editing

- Keep changes small and the process lightweight.
- Refine instructions based on actual use; distinguish tested behavior from unverified guidance.
- Provide a matching `.zh.md` Chinese review version for every Markdown document except `AGENTS.md`, and keep both versions in sync when making changes.
- Write README files for people discovering and using the skills. Keep repository maintenance instructions here.

## Commits

Commit or push only when the author explicitly requests it. Make each commit a coherent, reviewable improvement.
